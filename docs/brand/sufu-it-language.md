# SUFU — “Sufu it” language

## Product principle
“I came here because I need something. SUFU helps me get it done.”

The product should progressively turn this into a natural verb:

**Need something → Sufu it → Get it done.**

Examples:
- Need a plumber? **Sufu it.**
- Need a product? **Sufu it.**
- Need a job? **Sufu it.**
- Need customers? **Sufu it.**
- Need a supplier? **Sufu it.**
- Need something good? **Sufu it.**

## UX rule
“Sufu it” is a product action, not a slogan pasted everywhere. Use it where the user is asking SUFU to find, match, connect or facilitate an economic outcome.

## Tone
Short. Useful. Human. Local-first, globally understandable.

## Guardrail
Do not replace every button with “Sufu it”. Specific actions such as Send enquiry, Make offer, Accept quote, Pay securely and Leave review remain explicit when clarity matters.
