# SUFU journey UI

The journey component is an orientation layer, not a replacement for task-specific controls.

Completed stages use a check mark. The current stage is emphasized. Future stages remain quiet. Previous/current stages may navigate to relevant surfaces when navigation is useful.

The journey is intentionally horizontal and compact so it works on mobile without becoming a dashboard.

Canonical labels:
- Need something?
- Matched
- Connected
- Getting it done
- Done
