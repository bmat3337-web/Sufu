# SUFU product loop

**Need → Sufu it → Match → Connect → Agree → Transact → Get it done → Review → Reputation**

The UI expresses this as:

**Need something? → Matched → Connected → Getting it done → Done**

## Surfaces
- Home: initiate the need with **Sufu it**
- Explore: **Matched**
- Request detail: **Need / Connected**
- Inbox: **Connected**
- Engagement: **Getting it done / Done**
- Review: closes the loop and strengthens reputation

## Design rule
The journey indicator is a lightweight orientation device. It never replaces the specific action required on a screen.

Use explicit transaction language for high-consequence actions: Accept offer, Accept quote, Pay securely, Release payment, Dispute, Complete, Review.

## Brand objective
Over time, repeated successful use should make “Sufu it” feel like an ordinary verb for taking a need to the SUFU network.

Example:
**“I need a reliable plumber. I'll Sufu it.”**
